# Vibe Tasks

Vibe Tasks is a tiny early-stage task manager for students and founders who want a lightweight way to sort what matters today.

The app is currently a static React and TypeScript prototype. It shows a simple task list, priority labels, and a few product ideas for future planning.

## Current state

- Built as a Vite-style React app.
- Uses local in-memory sample tasks.
- No accounts, database, sync, tests, or deployment setup yet.
- Setup notes are incomplete on purpose for the Micki demo.

## Running locally

Install dependencies and start the development server.

The exact commands and environment requirements still need to be documented.
